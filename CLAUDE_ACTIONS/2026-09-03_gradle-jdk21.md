# Fijar JDK 21 para builds de Gradle (Android)

**Qué se cambió:** se creó `~/.gradle/gradle.properties` (no existía) con:
```
org.gradle.java.home=/usr/lib/jvm/java-21-openjdk
```

**Por qué:** el JDK por defecto del sistema es OpenJDK 26 (`archlinux-java status`), incompatible
con el Android Gradle Plugin — rompía `:react-native-ble-plx:compileDebugJavaWithJavac`
(`JdkImageTransform`/`jlink` sobre `core-for-system-modules.jar`) y las tareas
`configureCMakeDebug` de módulos nativos (reanimated, screens). JDK 21 ya estaba instalado
(`pacman -Qs jdk` → `jdk21-openjdk`), solo faltaba decirle a Gradle que lo usara.

**Alcance/implicaciones:** solo afecta a Gradle (todos los proyectos Gradle de este usuario en
esta máquina usarán JDK 21, no solo `Physical/app`). No toca el JDK por defecto del sistema
(`java -version` en una terminal normal sigue reportando 26) ni ninguna otra herramienta.
Sin este archivo, cualquier build de Android en este repo requiere exportar
`JAVA_HOME=/usr/lib/jvm/java-21-openjdk` a mano antes de `./gradlew`.

**Cómo replicarlo en otra máquina:** confirmar que existe un JDK 17 o 21 instalado
(`ls /usr/lib/jvm/`) y crear el mismo archivo apuntando a esa ruta.

**Cómo revertirlo:** borrar `~/.gradle/gradle.properties` (o solo la línea `org.gradle.java.home`
si el archivo llegara a tener más configuración después). Gradle volverá a usar el JDK del
`PATH`/`JAVA_HOME` del shell (JDK 26), y los builds de Android volverán a fallar hasta que se
exporte `JAVA_HOME` manualmente o se reponga esta config.
